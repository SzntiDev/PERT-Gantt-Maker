# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-29

### Added

- Interactive task input table with add/edit/remove functionality
- CPM (Critical Path Method) algorithm engine with full forward and backward pass
- Automatic PERT network diagram generation using vis-network (AOA format)
- Custom SVG-based Gantt chart with animated bars
- Critical path detection and visual highlighting (red) in both diagrams
- Dummy/fictitious activity generation to maintain network integrity
- Tripartite PERT nodes displaying Event ID, Early Time (ET), and Late Time (LT)
- Slack/float visualization in the Gantt chart
- Dark mode glassmorphism UI with modern aesthetics
- Responsive layout
